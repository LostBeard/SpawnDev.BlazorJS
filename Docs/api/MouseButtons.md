# MouseButtons

**Namespace:** `SpawnDev.BlazorJS.JSObjects`  
**Source:** `JSObjects/MouseButtons.cs`  

> A number representing one or more buttons. For more than one button pressed simultaneously, the values are combined (e.g., 3 is primary + secondary). https://developer.mozilla.org/en-US/docs/Web/API/MouseEvent/buttons#value

## Values

| Name | JSON Value | Description |
|---|---|---|
| `NoButton` | `0` | 0: No button or un-initialized |
| `PrimaryButton` | `1` | 1: Primary button (usually the left button) |
| `SecondaryButton` | `2` | 2: Secondary button (usually the right button) |
| `AuxiliaryButton` | `4` | 4: Auxiliary button (usually the mouse wheel button or middle button) |
| `FourthButton` | `8` | 8: 4th button (typically the "Browser Back" button) |
| `FifthButton` | `16` | 16 : 5th button (typically the "Browser Forward" button) |
